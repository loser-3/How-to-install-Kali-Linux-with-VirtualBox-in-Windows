How to install Kali Linux with VirtualBox in Windows

How to install kali linux in windows...





[ step - 1 ]

frist go to BIOS

check your CPU Virtualization Technology

then Enable CPU Virtualization Technology



[ step - 2 ]

search - https://www.virtualbox.org/ ( VirtualBox )

click download option

click VirtualBox platform packages Windows hosts & download

then Accept and download - VirtualBox Extension Pack



[ step - 3]

search kali.org & enter this site ( https://www.kali.org )

click download option & Choose Virtual Machines

suggest VirtualBox/Hyper-V ( select VirtualBox )

download VirtualBox



[ step - 4 ]

install VirtualBox & setup VirtualBox Extension Pack with mouse double click

Extract kali-linux zip file ( like - 7-Zip software & Extract to 'kali-linux-' )

create virtualbox folder

copy kali-linux extract file & paste kali-linux file in virtualbox folder



[ step - 5 ]

open VirtualBox then customize System Base Memory & go to VirtualBox setting option select Network then Enable Network Adapter NAT to Bridged Adapter

click Start ( wait few second )

user name - kali / password - kali

Enjoy with Kali Linux <3
